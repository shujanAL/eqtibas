# اقتباس (Eqtibas)

Eqtibas is a Laravel / PHP / MySQL platform for publishing and managing short quotes. Guests can browse and search; authenticated users can publish and manage only their own quotes.

راجع [DEPLOY_RENDER_AR.md](DEPLOY_RENDER_AR.md) لتعليمات النشر على Render باستخدام Docker وقاعدة MySQL خارجية.

See `FINAL_DELIVERY/RUN_INSTRUCTIONS.md` for setup and `FINAL_DELIVERY/COMPLETION_REPORT.md` for implementation status.
